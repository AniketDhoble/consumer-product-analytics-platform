# Consumer & Product Analytics Platform

A business-focused retail analytics project using Python, MySQL,
and SQL to analyze consumer, product, sales, regional, discount,
and profitability performance.

## Objective

Analyze consumer, product, sales, regional, discount, and
profitability performance to identify actionable business insights.

## Project Structure

- `datasets/raw/` — Original source data
- `datasets/interim/` — Temporary processing data
- `datasets/processed/` — Final cleaned and processed data
- `database/` — MySQL database scripts
- `documentation/` — Project documentation
- `reports/` — Profiling and validation reports
- `src/` — ETL, validation, profiling, and analytics modules
- `tests/` — Project testing scripts
- `logs/` — Pipeline and error logs

## Development Approach

The original dataset is never modified directly.

All data transformations are performed through Python processing
workflows. The processed data is validated before being loaded
into MySQL.

SQL and Python analytics modules are then used to generate
business-focused analytical results.
